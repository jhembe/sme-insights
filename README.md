# sme-insights

SME Insights is a mobile-first SaaS platform built for Tanzanian small and medium businesses to help them track sales, expenses, and overall business performance without relying on spreadsheets or accounting tools. I designed and developed the system end-to-end, using NestJS, PostgreSQL, and Prisma for the backend, and React with TypeScript for the frontend, implementing a multi-tenant architecture with secure JWT-based authentication and role-based access control. The platform enables business owners to manage products, customers, transactions, and team members while providing real-time analytics such as revenue trends, profit insights, and payment breakdowns. It is fully containerized and deployed in production using Docker and a reverse proxy, optimized for mobile usage and tailored to local payment methods like M-Pesa and Airtel Money.
